# Wekil - local coding agent

A single Windows exe: a local coding agent you talk to from Telegram. Runs fully on your PC with a local model (qwen3:4b via Ollama). Free.

Download wekil.exe, run it, and follow the on-screen steps (first run installs Ollama if missing and downloads the model, ~2.5 GB). Every device command needs your approval in Telegram before it runs.
